# Internationalization (i18n)

Multi-language support using i18next and react-i18next.

## Supported Languages

| Language | Code | Status |
|---|---|---|
| English | `en` | ✅ Complete |
| Amharic | `am` | ✅ Complete |
| Afan Oromo | `om` | ✅ Complete |

## Usage

### In Components

```tsx
import { useTranslation } from 'react-i18next'

function MyComponent() {
  const { t } = useTranslation()

  return (
    <div>
      <h1>{t('auth.loginTitle')}</h1>
      <p>{t('dashboard.welcome', { name: 'John' })}</p>
    </div>
  )
}
```

### Language Switcher

```tsx
import { LanguageSwitcher } from '@/components/LanguageSwitcher'

<LanguageSwitcher />
```

## Translation Files

```
src/i18n/
├── index.ts           # i18n configuration
└── locales/
    ├── en.json        # English translations
    ├── am.json        # Amharic translations
    └── om.json        # Afan Oromo translations
```

## Adding a New Language

1. Create `src/i18n/locales/fr.json` (example: French):

```json
{
  "auth": {
    "login": "Connexion",
    "register": "S'inscrire"
  }
}
```

2. Update `src/i18n/index.ts`:

```ts
import fr from './locales/fr.json'

i18n.init({
  resources: {
    en: { translation: en },
    am: { translation: am },
    fr: { translation: fr },  // Add here
  },
})
```

3. Update `LanguageSwitcher.tsx` to include French.

## Interpolation

Use `{{variable}}` for dynamic values:

```json
{
  "dashboard": {
    "welcome": "Welcome, {{name}}"
  }
}
```

```tsx
t('dashboard.welcome', { name: 'John' })
// Output: "Welcome, John"
```

## Configuration

In `src/i18n/index.ts`:

```ts
i18n
  .use(LanguageDetector)  // Auto-detect browser language
  .use(initReactI18next)
  .init({
    resources: { ... },
    fallbackLng: 'en',           // Default language
    interpolation: {
      escapeValue: false,         // React already escapes
    },
    detection: {
      order: ['localStorage', 'navigator'],
      caches: ['localStorage'],   // Save preference
    },
  })
```
